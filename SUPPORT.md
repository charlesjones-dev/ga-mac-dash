# Retirement and Support Policy

**GA Mac Dashboard retired in September 2026.** The project is unmaintained. No version is supported, and there will be no further maintenance, features, bug fixes, or security updates.

## Support and Security

Installation help, troubleshooting, bug reports, feature requests, pull requests, and security reports are no longer handled by this project. There is no ongoing support or security response process. Please do not open issues or pull requests expecting assistance or a fix.

Existing copies may continue to run, but compatibility with future macOS versions, Google Analytics, and other services is not maintained. The setup and build instructions are historical documentation, not a recommendation to install the retired application.

## Independent Forks and License

Independent forks are welcome under the existing [MIT License](LICENSE), including its copyright and permission notice requirements. The license is unchanged. Any support or maintenance offered by a fork is the responsibility of that fork's maintainers.

## External Distribution and Services

Retirement of this repository does not unpublish packages, remove store listings, disable existing installations, or cancel external services or subscriptions. Any such resources require separate review by their owners; this notice does not assert that they have been shut down.
